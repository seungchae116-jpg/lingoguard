# SafeLingo · 링고가드 (LingoGuard)

외국인 근로자를 위한 모국어 AI 현장안전 코치 — 「2026 AI·창업 아이디어 경진대회」 시제품

- 8개 언어 안전 브리핑 + 그림 퀴즈, AI 보호구 점검(사진·**실시간 카메라**), 그림 위험 신고, 관리자 현황판
- AI(YOLO11n 보호구 탐지)는 **기기 안에서** 실행 — 영상이 서버로 전송되지 않음
- 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 설치되고, 한 번 연 뒤에는 인터넷 없이도 실행

## 라이선스
- 보호구 탐지 모델: Ultralytics YOLO11n을 Construction-PPE 데이터셋으로 학습 — AGPL-3.0
- TensorFlow.js — Apache-2.0
